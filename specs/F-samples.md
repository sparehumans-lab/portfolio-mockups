# F. 새싹페이 — 진단·자문 샘플 문서

## 목적
공고 유형: 코드 진단, RFP 검수, 개발사 선정 자문. “결과물 형식과 판단 근거”를 보여주는 샘플.

## 기술 스펙
- 진단 보고서: 발견 8건(치명/높음/보통/낮음), 필터, 포함 체크 → 공수·견적 즉시 재계산(인일 단가는 `f_settings.rate`)
- RFP 검수: 10항목 체크 → 완성도 % 와 보완 안내
- 개발사 비교: 기준 5개 가중치 슬라이더 → 가중 평균 순위, 견적 중앙값 안내
- 모든 체크/가중치 변경은 `Repo.update` 로 DB 저장(문서가 “살아있는” 상태)

## 테이블
| 테이블 | 컬럼 |
|---|---|
| f_findings | id, sev, area, title, evidence, fix, man_days(≥0), included |
| f_rfp_items | id, label, hint, checked, pos |
| f_vendors | id, name, price, scores(jsonb) |
| f_criteria | id, label, weight(0~100), pos |
| f_settings | id('rate'), value |

## 남은 구현 작업
1. 단가 입력(`f_settings.rate`)을 화면에서 수정 가능하게 하고 재계산
2. 발견 사항 추가/수정/삭제 폼(CRUD 시연), 증빙 첨부란은 텍스트 링크로 대체
3. 결과 내보내기: 보고서 화면을 인쇄용 스타일(@media print)로 정리
4. 개발사 점수 편집 UI와 근거 메모 컬럼 추가
5. 슬라이더 입력 중 과도한 쓰기 방지(변경 확정 시 저장 또는 디바운스)

## 수용 기준
- 항목 포함 체크 → 인일·견적 즉시 변경, 새로고침 후 유지
- 가중치를 바꾸면 순위가 바뀜(예: 견적 가중 상향 시 저가 업체 상승)
- 발견 사항 추가/삭제가 목록과 합계에 반영

## 공고에 설명할 포인트
근거 있는 점수화, 평가 기준 공개, 중앙값 대비 저가 견적 검증 질문
